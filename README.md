## 🛠️ 기술 스택

### Client
`Unreal Engine` · `C++`
### Server
`Visual Studio` · `Winsock` · `C++` · `IOCP` · `TCP` · `UDP` · `Multithreading`


## 🎮 프로젝트 소개

**Unreal Engine Client와 C++ Socket Server로 구현하는 실시간 멀티플레이 아케이드 게임 프로젝트**


## 🎯프로젝트 목표

### Client
* 2D 아케이드 게임 플레이 구현
* 로비 및 게임 방 UI 구현
* 캐릭터 이동, 폭탄 설치 및 폭발 등 핵심 게임플레이 구현
* 서버로부터 전달받은 게임 상태를 기반으로 게임 화면 구성
### Server
* 로그인 → 로비 → 방 생성/참가 → 게임 플레이의 서버 흐름 구현
* 다중 게임 방 및 플레이어 관리
* 플레이어 이동, 폭탄, 충돌, 데미지 등 게임 상태 및 판정의 서버 authoritative 처리
* 게임 Tick 기반의 게임 상태 업데이트 및 동기화
* 클라이언트와 서버 간 게임 프로토콜 및 패킷 처리 구현


## 📖 프로젝트 목적

* 실시간 멀티플레이 게임을 위한 **클라이언트-서버 구조를 직접 설계하고 구현**
* Unreal Engine 기반의 클라이언트와 C++ 기반의 게임 서버를 분리하고, 서버가 게임의 주요 상태와 판정을 **Authoritative Server** 방식으로 관리
* IOCP 기반의 **비동기 네트워크 처리**, 다중 게임 방 관리, 게임 Tick 및 Job 기반 처리 등을 직접 구현
* 온라인 게임 서버의 기본적인 **구조와 동작 원리를 이해하고 검증**
